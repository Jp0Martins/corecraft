# CoreCraft — Tarefas Práticas

Repositório de entregas das tarefas práticas do programa **CoreCraft**, da comunidade **Bitcoin Coders**.  
O programa é uma mentoria focada em desenvolvimento com **Bitcoin Core**, abordando desde a construção de transações até a operação de um backend conectado ao node.

## Atividades

| Atividade | Descrição |
| --- | --- |
| **Atividade 1** | Fundamentos de transações Bitcoin |
| **Atividade 2** | Backend para criação e broadcast de transações |
| **Atividade 3** | Múltiplas wallets e estado interpretado |

## Estrutura do repositório

```text
corecraft/
├── atividade-1/
├── atividade-2/
├── atividade-3/
└── README.md
```

## Tecnologias

- ZMQ
- Python
- Bitcoin Core (signet)
- Flask
